# Créditos de som — Pokémon Lake

Todos os sons ambientes (pássaros, grilos, gotas de caverna, ondas, vento, chuva, passos, grama)
são **sintetizados em tempo real** pelo navegador com Web Audio (ruído filtrado + osciladores),
no código de `js/app.js` (bloco "REALISMO 6"). Nenhum arquivo de áudio externo é usado (0 KB baixados).
